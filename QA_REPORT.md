# Fedora Doctor — QA отчёт Reliability Monitoring

Дата проверок: 2026-11-17. Проверялась рабочая копия на Fedora Linux 44 / Python 3.14; GUI — в Qt offscreen. Проверки проводились без root. Отчёт описывает фактически выполненные проверки, но не сертифицирует приложение для всех систем.

В этой публичной копии опущены журнальные строки с локального компьютера, имена процессов, PID, точные времена событий, версии пакетов и другие значения, по которым можно идентифицировать частный диагностический случай.

## Сводка автотестов

- Объявлено в pytest suite: **54 случая** (50 тестовых функций, включая параметризацию на 5 случаев).
- PASS: **0**; FAIL: **0**; SKIPPED: **0**; BLOCKED: **54**.
- Причина BLOCKED: в доступном Python отсутствовал pytest. Тесты не запускались и не считаются пройденными.
- Ручные smoke-проверки ниже не входят в количество pytest cases.

## Непроверенные функции и ограничения

- Pytest suite заблокирован отсутствием pytest/pytest-qt; установка зависимостей из сети не выполнялась.
- Получение stack trace через `coredumpctl info` не проверено: доступ systemd bus был ограничен. Полные core dumps приложением не экспортируются и не сохраняются.
- DNF transaction ID и перечень файлов транзакций не собираются. Изменения ограниченного набора RPM определяются по снимкам метаданных.
- Перезапуски отдельных RPM/Flatpak процессов напрямую не отслеживаются; используются доступные записи systemd/journal.
- Зависания отмечаются только при явных сообщениях журнала.
- Kernel panic/oops и записи прежних загрузок зависят от хранения журнала и прав доступа.
- Метрики GPU/VRAM зависят от драйвера и доступных утилит/sysfs; универсальные датчики есть не на всех системах.
- Опрос может пропустить изменение, которое произошло и было отменено между снимками. Время обновления не доказывает причинность.
- Нативное GUI, экспорт из диалога, stack trace с debug symbols, работа после повторного входа в профиль и многочасовая нагрузка не проверялись.
- Установщик проверен синтаксически, но не запускался, поскольку он изменяет пользовательское virtualenv и desktop entry.

## Известные дефекты и BLOCKED

- **BLOCKED:** получение stack trace в окружении проверки из-за `Operation not permitted` при доступе к systemd bus.
- **BLOCKED:** запуск 54 pytest cases до появления pytest/pytest-qt.
- В перечисленных ручных smoke-сценариях других подтверждённых дефектов не обнаружено. Это не доказывает отсутствия ошибок.
